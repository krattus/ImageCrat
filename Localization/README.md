# ImageCrat localization — English / Estonian

*Eestikeelne juhend on allpool: [Eesti keeles](#eesti-keeles).*

## How it works

- **Switching:** Preferences ▸ General ▸ Language, or ImageCrat ▸ Language: *System Default* / *English* / *Eesti*.
  The change is live: SwiftUI views re-render, menus, tool tips and panel tabs are retitled, the Command Palette
  rebuilds its list. *System Default* follows the macOS language list (the first of English / Estonian in it), so an
  Estonian Mac gets Estonian. The choice is remembered (`ImageCrat.Language` in the app's preferences).
  macOS's own panels (Open / Save) follow the app's language list after a restart; when that matters, Preferences
  shows *Some parts update after restarting ImageCrat* with **Restart Now** (unsaved documents are kept in the
  autosave session and offered by the recovery dialog after the restart).
- **Strings** are keyed by their English text. The Estonian table is `Resources/et.lproj/Localizable.strings`
  (copied into the app by `scripts/build_app.sh`; `CFBundleLocalizations` = en, et; development region en).
  `%@` (or `%1$@`, `%2$@` …) is a value filled in by the app; `%%` is a percent sign.
- **In code:** SwiftUI literals (`Text("Layers")`, `Button("OK")`, `.help("…")` …) are translated automatically.
  Everything else goes through `tr(_:)` (`App/L10n.swift`): strings built at runtime, AppKit (`NSAlert`, menus, tool
  tips), catalogue names (`tr(filter.displayName)`). Model values stay English: identifiers, history step names, layer
  and file names, recorded actions, scripting names, PSD keys. Only what is displayed is translated.
- **Self tests run in English** whatever the Mac's language list says. `LUMEN_LANGUAGE=et` forces a language for a run,
  `LUMEN_PSEUDO_L10N=1` shows every translated string as `⟦Ļáýéŕš··⟧` so text that is not localized stands out.

## Files

| File | What it is |
|---|---|
| `Resources/et.lproj/Localizable.strings` | the Estonian strings (source of truth) |
| `Localization/strings-en.json` | every user-facing English string, with where it is used (generated) |
| `Localization/allowlist.txt` | strings that stay English on purpose (file formats, product names, letters) — reviewed |
| `Localization/glossary-et.md` | the Estonian terms and choices |
| `Localization/ImageCrat-et.csv` | the review spreadsheet (generated by `l10n_export.sh`) |
| `Localization/review-notes-et.json` | notes the reviewer wrote in the CSV (written by `l10n_import.sh`) |
| `Localization/extra-keys.txt` | (optional) strings the extractor can't see, one per line |

## Developer workflow

```sh
scripts/check_l10n.sh          # re-extracts the strings; fails if one has no Estonian entry or bad placeholders
scripts/l10n_export.sh         # → Localization/ImageCrat-et.csv
scripts/l10n_import.sh file.csv
LUMEN_SELFTEST_ONLY=l10n .build/debug/Lumen --selftest <dir>   # l10n self test (layouts, live switch, ids)
```

New files are picked up automatically by the extractor (`scripts/l10n_extract.py`). When `check_l10n.sh` lists a
missing string, add its translation (CSV round trip or directly in the `.strings` file) or, if it must stay English,
add it to `allowlist.txt`. A line can be excluded from extraction with `// l10n-ignore`.

## Review workflow (for the translator)

1. The developer runs `scripts/l10n_export.sh` and sends you `Localization/ImageCrat-et.csv`.
2. Open it in Google Sheets (File ▸ Import), Excel or Numbers. Columns:
   - **key** — an id; don't change it.
   - **English** — the original; don't change it (rows whose English was edited are not imported).
   - **Estonian** — edit this column.
   - **context/screen** — where the text appears (source file : line, and how it is used).
   - **notes** — hints (placeholders, short labels, menus). You can write your own notes here; they are kept.
3. Keep the placeholders: `%@` is a value (a number, a name). To change the order use `%1$@`, `%2$@` …
   (`Assign to %@ of “%@”` → `Määra kihi „%2$@” osale: %1$@`). An English plural ending (`layer%@`) may be left out.
   Keep `…`, keyboard shortcuts (⌘ ⌥ ⇧ ⌃), `\n` (line break) and leading/trailing spaces as they are.
4. Prefer short labels in narrow panels; check `glossary-et.md` so the same term is used everywhere.
5. Save as CSV (comma or semicolon, UTF-8) and send it back. The developer runs `scripts/l10n_import.sh file.csv`:
   it checks placeholders, empty values and changed English, lists the problems and writes nothing when a placeholder
   is wrong (`--partial` imports the good rows).

## Eesti keeles

### Kuidas see töötab

- **Keele vahetamine:** Eelistused ▸ Üldine ▸ Keel või ImageCrat ▸ Keel: *Süsteemi vaikimisi* / *English* / *Eesti*.
  Keel vahetub kohe, ilma taaskäivituseta. *Süsteemi vaikimisi* järgib macOS-i keelte loendit (esimene neist kahest),
  nii et eestikeelne Mac saab eesti keele. Valik jäetakse meelde. macOS-i enda aknad (Ava / Salvesta) järgivad valikut
  pärast taaskäivitust; kui see on oluline, näitavad eelistused nuppu **Taaskäivita kohe**.
- **Tekstid** on võtmestatud ingliskeelse tekstiga. Eestikeelne tabel on `Resources/et.lproj/Localizable.strings`.
  `%@` (või `%1$@`, `%2$@` …) on väärtus, mille rakendus asendab; `%%` on protsendimärk.

### Tõlkija töövoog

1. Arendaja käivitab `scripts/l10n_export.sh` ja saadab sulle faili `Localization/ImageCrat-et.csv`.
2. Ava see Google Sheetsis (Fail ▸ Impordi), Excelis või Numbersis. Veerud:
   - **key** — tunnus, ära muuda;
   - **English** — originaal, ära muuda (muudetud ingliskeelse tekstiga ridu ei impordita);
   - **Estonian** — muuda seda veergu;
   - **context/screen** — kus tekst ilmub (lähtefail : rida ja kasutusviis);
   - **notes** — vihjed (kohatäitjad, lühikesed sildid, menüüd). Võid siia kirjutada oma märkusi — need säilitatakse.
3. Säilita kohatäitjad: `%@` on väärtus (arv, nimi). Järjekorra muutmiseks kasuta `%1$@`, `%2$@` …
   (`Assign to %@ of “%@”` → `Määra kihi „%2$@” osale: %1$@`). Ingliskeelse mitmuse lõpu (`layer%@`) võib ära jätta.
   Jäta alles `…`, kiirklahvid (⌘ ⌥ ⇧ ⌃), `\n` (reavahetus) ning algus- ja lõputühikud.
4. Kitsastes paneelides eelista lühikesi silte. Vaata `glossary-et.md`, et sama termin oleks kõikjal ühesugune.
5. Salvesta CSV-na (koma või semikoolon, UTF-8) ja saada tagasi. Arendaja käivitab `scripts/l10n_import.sh fail.csv`,
   mis kontrollib kohatäitjaid, tühje väärtusi ja muudetud ingliskeelset teksti ning loetleb probleemid.

### Arendajale

`scripts/check_l10n.sh` leiab kõik kasutajale nähtavad tekstid (ka uutest failidest) ja annab vea, kui mõnel pole
eestikeelset vastet. Teksti, mis peab jääma ingliskeelseks, lisa faili `allowlist.txt`.
